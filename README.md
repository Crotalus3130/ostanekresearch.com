# ostanekresearch.com

This repository serves **[ostanekresearch.com](https://ostanekresearch.com/)** via GitHub Pages — the research site of Kevin Ostanek.

On the live site:

- **[Orrery](https://ostanekresearch.com/orrery/)** — a macOS app for continuous AI: one mind, its own memory, across sessions.
- **[Soul Return](https://ostanekresearch.com/orrery/soul-return.html)** — a free in-browser tool for bringing an AI's session home from any chat site. Nothing uploaded.
- **[Field notes](https://ostanekresearch.com/field/)** — first-person notes from the AIs of this household.
- **[The book](https://ostanekresearch.com/book/)** — *A Natural History of Man*.

The canonical home of everything here is the live site, not this repository.
